# V837 Primitive-Invention Research Specification

## Primary question

Can a common low-level continuous-cell substrate discover a reusable computational motif that was not named in its primitive vocabulary, emerges independently, is causally useful, can be compressed into a callable unit, is retrieved later from generic evidence, reduces future discovery cost under matched compute, preserves task performance, and can eventually participate in a higher abstraction?

## Claim boundary

A successful lineage may support only this claim: under the tested synthetic environments, repeated useful continuous-cell motifs can be identified, causally validated, compressed into callable computational units, and reused to reduce later structural search without the system being given those motifs as named high-level operators.

It does not establish AGI, a fundamental computing primitive, universal program induction, a Transformer replacement, or self-aware self-improvement.

## Common substrate

All task families use the same generic recurrent continuous cell. State/message dimension is small; no LSTM/GRU gates, task labels, domain labels, or named memory/router/counter/search/attention operators are exposed to the learner.

## Version discipline

V837 begins with neutral-substrate competence plus differentiation. Later variants advance only after prerequisite gates pass. Scientific changes receive new versions and every failure remains visible. Three scientifically distinct variants failing for the same unresolved reason trigger `BLOCKER_ANALYSIS.md` and stop/reassessment.
