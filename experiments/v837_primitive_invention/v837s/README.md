# V837s — Global coupling × dynamic-control interaction

V837s is a conditionally authorized follow-up to V837r. V837r found a coupling-specific partial recovery: rank-4 and rank-8 cross-block recurrent coupling reached 3/5 while exact local-only parameter controls remained 2/5. Its machine-readable decision state therefore authorized one interaction test with the already frozen V837p dynamic scalar state modulator.

## Frozen question

Does the V837p dynamic scalar recurrent-state modulator become sufficient when recurrent computation also has the best justified V837r global cross-dimensional coupling?

## Conditions

- `S0_local_no_modulation`: historical local recurrence, no dynamic modulation.
- `S1_local_dynamic_scalar`: exact V837p dynamic scalar candidate modulation, no global coupling.
- `S2_rank4_no_modulation`: V837r rank-4 cross-block-only coupling, no dynamic modulation.
- `S3_rank4_dynamic_scalar`: rank-4 cross-block coupling plus exact V837p multiplicative dynamic scalar modulation.
- `S3C_rank4_matched_dynamic_additive`: same rank-4 coupling and same dynamic-scalar network/parameter count, but the scalar is added to the candidate preactivation instead of multiplying recurrent-state access.

All conditions use the same 10×4 local state, 40 total recurrent dimensions, 55-edge graph, 4× unique-data regime, optimizer, task seeds, validation seeds, five paired initialization replicates and historical capacity gate.

V837s does not add a vector gate, shared state, attention, router, memory, structural search, primitive mining, or fresh-audit data.
