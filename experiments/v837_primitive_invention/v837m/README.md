# V837m — stable general linear state transport

V837m is the first post-calibration Transmutor cell-law diagnostic. V837l established that a small GRU can solve all five task families when unique development data is increased to 4x while optimizer steps stay fixed. V837m therefore evaluates four neutral-cell update conditions under that same calibrated data regime.

The tested mechanism is a stable learned linear state transport path, compared with the historical cell, V837g scalar persistence, and an exactly parameter-matched additive recurrent projection that stays inside the tanh bottleneck.

This is a fixed-topology high-capacity screen only. Primitive mining, fresh audit, and full structural search remain blocked unless the unchanged >=4/5 capacity prerequisite is met.
