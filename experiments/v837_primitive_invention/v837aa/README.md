# V837aa — Candidate-Law Alignment Audit

V837aa is a diagnosis-only mechanistic audit of the frozen V837y Y3 parent. It reruns only the 25 Y3 family×replicate fits and asks whether the ten independently parameterized local candidate cells have already converged on one reusable recurrent/message law, the same law in different exact tanh-compatible signed/permuted bases, a small stable vocabulary of cell laws, or genuinely heterogeneous local laws.

No candidate parameters are shared in V837aa. No basis adapters, shared input projection, graph change, message-timing change, structural search, primitive mining, fresh-audit data, V837ab implementation, or V838 experiment is permitted.

Primary sharing evidence is the recurrent/message candidate core `Ws + Wm + b`. `Wx` and `Wo` are audited separately so specialized interfaces cannot erase evidence of a shared computational core.
