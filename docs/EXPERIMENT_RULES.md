# Experiment Rules

1. Preserve failures.
2. Define pass/fail criteria before interpreting results.
3. Separate proposal from proof.
4. Count discovery/search cost, not only final model size.
5. Use held-out tests for claims of transfer/generalization.
6. Record seeds, budgets, thresholds, and resource proxies.
7. Never mark reconstructed code as original source.
8. Prefer negative controls and adversarial tests after a positive result.
9. Distinguish synthetic evidence from real-world claims.
10. Every new experiment should identify its parent experiments and what uncertainty it targets.
